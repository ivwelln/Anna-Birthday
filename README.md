# Birthday Slides

Небольшой сайт-поздравление на `FastAPI` с одной публичной страницей `/` и простой админкой `/admin`.

## Что уже реализовано

- Главная страница с анимацией печатания текста.
- Появление изображений после текста.
- Автоматическая карусель, если на слайде больше трёх изображений.
- Кнопка перехода к следующему слайду с отдельным текстом для каждого слайда.
- Анимации смены слайдов.
- Админка без авторизации с настройкой:
  - порядка слайдов;
  - текста кнопки;
  - расположения текста и изображений;
  - нескольких текстовых блоков на одном слайде;
  - нескольких изображений на одном слайде;
  - размера текста, цвета текста, выравнивания;
  - ширины и максимальной высоты изображений.
- Хранение данных в `data/site_content.json`.
- Загрузка изображений в `app/static/uploads/`.

## Музыка

Добавь любой аудиофайл в директорию `app/static/audio/`.

Пример:

```text
app/static/audio/my-track.mp3
```

Сайт автоматически найдёт первый аудиофайл в этой директории и подключит его на главной странице.

## Запуск

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn app.main:app --reload
```

После запуска:

- главная страница: `http://127.0.0.1:8000/`
- админка: `http://127.0.0.1:8000/admin`

## Тесты
